## 1-page discussion

Формула FLOPs совпала с подсчётом операций по слоям на обеих выборках.

Для памяти MAPE составляет 28,02% на калибровке и 16,94% на проверке, RMSE на проверке - около 113 МБ. На проверочной выборке относительная ошибка ниже, однако оценка пикового потребления памяти остаётся приближённой.

Для времени MAPE составляет 22,67% на калибровке и 21,61% на проверке. Для энергии - 16,20% и 16,47% соответственно. RMSE на проверке составляет 30,31 мс для времени и 2,22 Дж для энергии. Близкие значения MAPE на двух выборках показывают, что на выбранных проверочных точках относительная точность существенно не ухудшилась.

Думаю, ошибки связаны с упрощениями в формулах. Для памяти мы складываем все активации, хотя они не обязательно хранятся одновременно, а временные буферы вообще не считаем. Для времени берём одну производительность GPU для всех слоёв и размеров входа - возможно, из-за этого формула не везде хорошо совпадает с замерами. Энергия зависит от предсказанного времени, поэтому ошибка времени попадает и в её расчёт.
